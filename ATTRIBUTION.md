The font licence allows bundling with software; modified fonts must be renamed.
MoneyKeep does not modify the fonts. The desktop app bundles Archivo, Inter and
Geist Mono for the start screen only (app-desktop.md revision 40), each with its
OFL text beside it; everywhere else it uses the fonts installed on the computer (or
the one chosen in Settings → Display). Icons are to be drawn in code or made
for the project, never taken from any target product. The 24 book pictures come from
free-licence stock photos (Pexels, Pixabay and Unsplash licences allow use and changes in
an app without credit; credit is given here anyway); each source is listed above and in
`docs/specs/data/book-pictures.csv`.
