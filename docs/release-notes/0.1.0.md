# MoneyKeep 0.1.0

MoneyKeep keeps the books for a household or a small business on your own computer.
Every amount goes into one ledger where both sides always balance, so your accounts,
budgets, investments, invoices and bills all agree with each other. Your books are
files you own; nothing is sent anywhere unless you set up a connection yourself.

This is the first public release. It is early software: please read
[Known limits](../known-limits.md) and keep backups of anything you put in it.

## What's in 0.1.0

**Everyday money**

- Accounts and registers with running balances, split transactions and reconciling
  against your statements.
- Ready-made lists of accounts to start a new book from.
- Import from bank and card files (`.ofx`, `.qfx`, `.qbo`, `.qif`, `.csv`). Every
  import is shown for review first, nothing is added until you choose **Add to
  books**, and every import can be undone. Rules can fill in categories for you, and
  likely duplicates are pointed out.
- A watched folder: files you save there are picked up for review.
- Scheduled and repeating transactions with reminders.
- Monthly budgets, with suggestions and rollover.
- Reports for spending, income and expenses, net worth and cash flow, with charts,
  exportable as CSV. A Home dashboard you can arrange.
- A subscriptions check that finds repeating payments and warns about price rises and
  charges after you cancelled.

**Investments**

- Stocks, funds, options, bonds and crypto in investment accounts, with lots, cost
  basis, realized and unrealized gains, investment income and performance.
- Import from investment statement files and broker CSV, JSON and XML downloads.
- Splits, reinvested dividends, mergers, spin-offs and symbol changes. Possible wash
  sales are flagged with the amounts for your tax forms.

**Small business and nonprofits** (turned on per book in Settings → Features)

- Customers, items, estimates, invoices with PDFs, payments, deposits, credit memos
  and sales tax.
- Vendors, bills, bill payments and checks, vendor credits, purchase orders, and 1099
  amounts for each vendor.
- Who-owes-what (A/R and A/P aging), balance sheet, profit and loss.
- Classes, locations, and nonprofit funds with restricted money and their statements.
- Projects with budgets and billable costs, customer statements and late fees,
  invoice templates with your logo.
- Expenses with receipt pictures and PDF expense reports, and mileage with standard
  rates.

**Connections and capture** (all optional)

- Bank and card connections through services and banks that offer an official way in,
  payment-processor payouts matched to your deposits, and brokerage connections.
- Phone capture: snap a receipt or log a trip on your phone and send it to MoneyKeep
  on your computer over your Wi-Fi, or through your own Cloudflare account. Setup is
  explained in [phone capture](../deploy/phone-capture.md).

**Safety**

- Password-protected books, with a recovery key shown once.
- Automatic backups of every book (see [Backups](../help/backups.md)).
- A history of every change, and undo.
- Shareable definition files for import layouts, rules, categories and securities.
  They hold data only; nothing in them is ever run.
- An optional AI assistant connection, a separate program that is off for every book
  until you turn it on in Settings → Security.

## Install

### Windows (64-bit)

- **With MoneyKeep Launcher:** install the launcher, then choose **Install** on
  MoneyKeep. It downloads the setup, checks it and runs it. Windows asks for
  administrator permission.
- **From the release:** download `moneykeep-0.1.0-windows-x64-setup.exe` and run it.
  It installs MoneyKeep for all users in `C:\Program Files\MoneyKeep` (Windows asks
  for administrator permission), with a Start menu shortcut and, if you choose, a
  desktop shortcut. The phone capture server is included.

The setup is not signed yet, so Windows SmartScreen may warn: choose **More info**,
then **Run anyway**.

A newer setup updates MoneyKeep in place and keeps your books and settings. To remove
MoneyKeep, use Settings > Apps > Installed apps; your books are never touched.

### Mac (macOS 11 or later, Apple silicon and Intel)

- **From the release:** download `moneykeep-0.1.0-macos-universal.dmg`, open it and
  drag MoneyKeep to Applications.
- **With MoneyKeep Launcher:** on a Mac the launcher can't install MoneyKeep yet (see
  [Known limits](../known-limits.md)). Install it from the release as above; the
  launcher then finds it, opens it and tells you when a new version is out.

This Mac build is not yet signed with an Apple Developer ID, so macOS warns the first
time you open it. Right-click (or Control-click) MoneyKeep in Applications, then choose
**Open**, and confirm. If macOS doesn't offer **Open**, go to System Settings > Privacy
& Security, scroll down and choose **Open Anyway** next to MoneyKeep. You only need to
do this once.

## Checking your download

Each release has a file called `SHA256SUMS.txt`. It lists a fingerprint (a SHA-256
checksum) for every file in the release. MoneyKeep Launcher checks it for you. To check
a file yourself:

- **Windows:** open PowerShell in the folder with the file and run
  `Get-FileHash .\moneykeep-0.1.0-windows-x64-setup.exe -Algorithm SHA256`
- **Mac:** open Terminal in the folder with the file and run
  `shasum -a 256 moneykeep-0.1.0-macos-universal.dmg`

Compare the long string it prints with the one next to the file's name in
`SHA256SUMS.txt` (capital and small letters count as the same). If they differ, don't
open the file: download it again.
