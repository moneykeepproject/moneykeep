# MoneyKeep 0.1.3

MoneyKeep 0.1.3 tidies up Home's Attention list and the page you see after an import,
and it is released together with MoneyKeep Launcher 0.1.3 and a new member of the
family, ShareKeep. It includes everything in [0.1.2](0.1.2.md) (the Mac file-window
fix). For everything MoneyKeep does, see the [0.1.0 release notes](0.1.0.md) and the
[0.1.1 notes](0.1.1.md) (the Mac build), and please read [Known
limits](../known-limits.md).

## What's new in 0.1.3

- **Attention lists only imports with something to do.** Home → Attention used to show
  lines such as "Import waiting for review: SnapTrade — Schwab (0 rows)", sometimes
  several times. An import is now listed once, and only while it holds something for
  you. The line says what: "(3 rows to review)", "(nothing new to add)" when every row
  is already in your books, or "(holdings differ)" when a brokerage's holdings don't
  match the book.
- **Brokerage syncs with nothing new no longer pile up.** A SnapTrade sync that finds
  no new activity, and holdings that agree with your book, leaves no empty import
  behind. Empty imports left by earlier syncs are cleared at the next sync.
- **Brokerage activity is counted.** A feed's "new transactions to review" line, its
  **Review** button under Settings → Connections and its band in the register now
  count investment rows as well as bank rows.
- **Reconcile now says which account.** After **Add to books**, each reconciliation
  MoneyKeep offers is on its own line with the account's name, the statement balance
  and its date, followed by its **Reconcile now** button. Before, a file with several
  accounts showed a row of identical buttons.
- **Mac: choosing a file no longer closes MoneyKeep** (from 0.1.2). File windows slide
  down from the top of MoneyKeep's window; choose **Cancel** to close one.
- **ShareKeep joins the MoneyKeep Apps.** It keeps a household's shared expenses, and
  MoneyKeep Launcher 0.1.3 lists it next to MoneyKeep.
- **MoneyKeep Launcher.** Launcher 0.1.0 and 0.1.1 offer their update but then fail
  with an error that names another product's launcher. If you use one of them,
  download MoneyKeep Launcher 0.1.3 from its release and install it over the old one,
  once; from then on it updates itself.

## Install

### Windows (64-bit)

- **With MoneyKeep Launcher:** install the launcher, then choose **Install** on
  MoneyKeep. It downloads the setup, checks it and runs it. Windows asks for
  administrator permission.
- **From the release:** download `moneykeep-0.1.3-windows-x64-setup.exe` and run it.
  It installs MoneyKeep for all users in `C:\Program Files\MoneyKeep` (Windows asks
  for administrator permission), with a Start menu shortcut and, if you choose, a
  desktop shortcut. The phone capture server is included.

The setup is not signed yet, so Windows SmartScreen may warn: choose **More info**,
then **Run anyway**.

A newer setup updates MoneyKeep in place and keeps your books and settings. To remove
MoneyKeep, use Settings > Apps > Installed apps; your books are never touched.

### Mac (macOS 11 or later, Apple silicon and Intel)

- **From the release:** download `moneykeep-0.1.3-macos-universal.dmg`, open it and
  drag MoneyKeep to Applications.
- **With MoneyKeep Launcher:** on a Mac the launcher can't install MoneyKeep yet (see
  [Known limits](../known-limits.md)). Install it from the release as above; the
  launcher then finds it, opens it and tells you when a new version is out.

This Mac build is not yet signed with an Apple Developer ID, so macOS warns the first
time you open it. Right-click (or Control-click) MoneyKeep in Applications, then choose
**Open**, and confirm. If macOS doesn't offer **Open**, go to System Settings > Privacy
& Security, scroll down and choose **Open Anyway** next to MoneyKeep. You only need to
do this once.

## Checking your download

Each release has a file called `SHA256SUMS.txt`. It lists a fingerprint (a SHA-256
checksum) for every file in the release. MoneyKeep Launcher checks it for you. To check
a file yourself:

- **Windows:** open PowerShell in the folder with the file and run
  `Get-FileHash .\moneykeep-0.1.3-windows-x64-setup.exe -Algorithm SHA256`
- **Mac:** open Terminal in the folder with the file and run
  `shasum -a 256 moneykeep-0.1.3-macos-universal.dmg`

Compare the long string it prints with the one next to the file's name in
`SHA256SUMS.txt` (capital and small letters count as the same). If they differ, don't
open the file: download it again.
