# MoneyKeep 0.1.4

MoneyKeep 0.1.4 fixes phone capture, which could not start in 0.1.3. Everything else
is as in [0.1.3](0.1.3.md). For everything MoneyKeep does, see the [0.1.0 release
notes](0.1.0.md) and the [0.1.1 notes](0.1.1.md) (the Mac build), and please read
[Known limits](../known-limits.md).

## What's new in 0.1.4

- **Phone capture starts again.** In 0.1.3 the phone app showed "MoneyKeep couldn't
  start" on every phone, over Wi-Fi and Cloudflare alike. Your computer, Cloudflare and
  your pairing were fine: the phone app inside the 0.1.3 release was damaged when it
  was made smaller for download. Once 0.1.4 is installed on your computer, open
  MoneyKeep Capture on your phone while the computer is on. It fetches the repaired app
  by itself; nothing you saved on the phone is lost and you don't need to pair again.
  If the old message still shows, close the app completely and open it again.
- **A damaged phone app can't be released again.** Building a release now checks the
  phone app and stops if it would not start.
- **The phone app loads faster.** It no longer downloads its program twice on the
  first start.
- **Clearer reasons when the phone app can't start.** The reason is now written to the
  browser's console, which helps when you report a problem.
- **"Install app" works behind Cloudflare sign-in.** The phone app's install details are
  now fetched with your Cloudflare sign-in, so the browser can offer to install it.

## For other Keep apps

MoneyKeep's ledger crates can now be copied into another app and built on their own,
with none of MoneyKeep's apps beside them. The copy set is `mk-core`, `mk-ledger`,
`mk-store`, `mk-import`, `mk-capture-api`, `mk-commands` and `mk-connect`, and it builds
and passes its own tests on its own from this release (checked by `cargo xtask
standalone`). Copy them from a released version only.

## Install

### Windows (64-bit)

- **With MoneyKeep Launcher:** choose **Install** (or **Update**) on MoneyKeep. It
  downloads the setup, checks it and runs it. Windows asks for administrator
  permission.
- **From the release:** download `moneykeep-0.1.4-windows-x64-setup.exe` and run it.
  It installs MoneyKeep for all users in `C:\Program Files\MoneyKeep` (Windows asks
  for administrator permission), with a Start menu shortcut and, if you choose, a
  desktop shortcut. The phone capture server is included and is updated too.

The setup is not signed yet, so Windows SmartScreen may warn: choose **More info**,
then **Run anyway**.

A newer setup updates MoneyKeep in place and keeps your books and settings. To remove
MoneyKeep, use Settings > Apps > Installed apps; your books are never touched.

### Mac (macOS 11 or later, Apple silicon and Intel)

- **From the release:** download `moneykeep-0.1.4-macos-universal.dmg`, open it and
  drag MoneyKeep to Applications.
- **With MoneyKeep Launcher:** on a Mac the launcher can't install MoneyKeep yet (see
  [Known limits](../known-limits.md)). Install it from the release as above; the
  launcher then finds it, opens it and tells you when a new version is out.

This Mac build is not yet signed with an Apple Developer ID, so macOS warns the first
time you open it. Right-click (or Control-click) MoneyKeep in Applications, then choose
**Open**, and confirm. If macOS doesn't offer **Open**, go to System Settings > Privacy
& Security, scroll down and choose **Open Anyway** next to MoneyKeep. You only need to
do this once.

## Checking your download

Each release has a file called `SHA256SUMS.txt`. It lists a fingerprint (a SHA-256
checksum) for every file in the release. MoneyKeep Launcher checks it for you. To check
a file yourself:

- **Windows:** open PowerShell in the folder with the file and run
  `Get-FileHash .\moneykeep-0.1.4-windows-x64-setup.exe -Algorithm SHA256`
- **Mac:** open Terminal in the folder with the file and run
  `shasum -a 256 moneykeep-0.1.4-macos-universal.dmg`

Compare the long string it prints with the one next to the file's name in
`SHA256SUMS.txt` (capital and small letters count as the same). If they differ, don't
open the file: download it again.
